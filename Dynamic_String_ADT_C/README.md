# Dynamic String ADT in C

## Project Name
Dynamic_String_ADT_C

## Description

This project implements a Dynamic String Abstract Data Type (ADT) using C language.

Unlike normal character arrays, this implementation uses dynamic memory allocation with malloc() and realloc().

## Features

- Create dynamic string
- Push back character
- Remove last character
- Find string size
- Access character by index
- Clear string
- Concatenate two strings
- Insert character at specific position
- Delete character from specific position
- Replace character
- Find substring
- Free allocated memory
